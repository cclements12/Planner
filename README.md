# Planner
Collaborative Capstone Project!

Getting Started:

Built on Python with Flask, please ensure that Flask is installed via pip for Python to launch the associated project.

Use "flask -A Planner run" from the project's root directory to run the project locally at URL: http://127.0.0.1:5000/ or "flask -A Planner run --debug" for additional debugging.

Requires "pip install passlib" for password encryption capabilities

Database initialized through http://127.0.0.1:5000/initialize app route and messages printed by http://127.0.0.1:5000/messages for testing
